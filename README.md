# LocalSecure

**خصوصيتك تبدأ من جهازك.**

صفحة ثابتة باللغة العربية لتنقيح النصوص وتشفير الملفات محلياً في المتصفح. لا يوجد خادم تطبيق أو اعتماديات بناء.

## التشغيل والنشر

- افتح `index.html` محلياً لتجربة تنقيح النصوص.
- تتطلب واجهة التشفير `crypto.subtle`، وهي متاحة في النشر عبر HTTPS وعلى `localhost` في المتصفحات الحديثة.
- على Vercel، اربط مستودع GitHub واختر **Other** كإطار العمل، واترك أمر البناء ومجلد الإخراج فارغين؛ ملفات الموقع موجودة في جذر المشروع.
- يمكن أيضاً نشر المجلد مباشرةً باستخدام Vercel CLI بعد تثبيته وتسجيل الدخول.

## الخصوصية والتشفير

التنقيح والتشفير يجريان داخل المتصفح. التشفير يستخدم AES-256-GCM ومفتاحاً مشتقاً عبر PBKDF2-HMAC-SHA-256 مع salt عشوائي 16 بايت و600,000 دورة وIV عشوائي 12 بايت.

الملف الناتج `.lsec` يحتوي على ترويسة `LSECURE1` (8 بايت)، ثم salt (16 بايت)، ثم IV (12 بايت)، ثم النص المشفر مع وسم المصادقة. لا يحتوي الملف على كلمة المرور. لا يمكن استرجاع الملف من دون كلمة المرور؛ كما أن هذه النسخة لا توفر أداة فك التشفير بعد.

## تنقيح النصوص

الفحص يبحث عن قيم مفاتيح API والأسرار والرموز، وعناوين البريد الإلكتروني، وتسلسلات الأرقام الطويلة المشابهة لأرقام البطاقات. الفحص نمطي وقد يفوّت بعض الأسرار أو يطابق نصوصاً عادية؛ راجع النتيجة قبل مشاركتها.
